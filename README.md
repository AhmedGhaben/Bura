# Bura Card Game

A Python implementation of the Bura card game developed for the
Python Development Practice course.

## Planned Features

- Graphical user interface
- Player vs Player mode
- Player vs Computer mode
- Multiple bot difficulty levels
- AI opponent
- Game statistics and additional features

## Game

Bura is a trick-taking card game in which players try to collect
at least 31 points by winning valuable cards.
